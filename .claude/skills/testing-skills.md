# Compétences de test

- Tests unitaires : Jest avec `@nestjs/testing` pour le backend ; React Testing Library pour le frontend.
- Tests e2e : utiliser supertest pour les endpoints API.
- Mocker les dépendances externes (service email, appels AI).
- Couverture visée : 80 %.
- Tests manuels : utiliser `curl` pour tester les endpoints ; simuler des parcours utilisateur complets.
- Vérifier les codes HTTP et les structures de réponse.
