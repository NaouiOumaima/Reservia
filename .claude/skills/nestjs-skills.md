# Compétences NestJS

- Modules : organiser par domaine ; garder les contrôleurs minces et les services épais.
- DTO : utiliser `class-validator` pour la validation.
- Guards : utiliser `JwtAuthGuard` ; la vérification des rôles se fait en ligne dans les contrôleurs.
- Base de données : Mongoose avec schémas dans `src/database/schemas/`.
- Configuration : utiliser `ConfigService` pour les variables d’environnement.
- Tests : tests unitaires avec `@nestjs/testing` et e2e avec supertest.
- Gestion des erreurs : utiliser les exceptions HttpException intégrées.
